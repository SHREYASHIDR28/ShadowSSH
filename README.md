# ShadowSSH — A Real-Time AI System That Engages and Deceives Hackers

An autonomous, behavior-aware cyber deception system that dynamically adapts its responses to attackers using real-time behavioral profiling and controlled generative execution.

## Key Features
- SSH-based deception interface
- Real-time attacker behavior observation
- Autonomous decision-making engine
- Controlled Generative AI execution layer
- Closed feedback loop architecture

## Architecture Overview
SSH Interaction → Behavior Observation → Attacker Profiling → Decision Engine → GenAI Execution → Feedback Loop

## Technologies Used
- Python
- Paramiko (SSH)
- Behavioral Feature Engineering
- Rule-based / ML-ready Profiling
- Generative AI (API-agnostic)

## Status
Core system implemented and validated.  
ML-based profiling and evaluation modules are planned enhancements.
